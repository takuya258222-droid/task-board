・「完了」は元のSlackメッセージへの✅として反映されます（次の同期タイミング: 平日 8:45／10:30／12:00／15:00／16:00／17:30／19:30）。完了・削除・戻す・失注/終了は押した瞬間にボード表示へ反映され、裏側の実適用は次の同期です。反映待ちの間は、各カードや完了済みタブの「取り消す」から操作を取り消して、タスクを操作できる状態に戻せます（同期で反映済みのものは取り消せません）。
・面談の「完了」はその段階への✅です（内定確認への✅＝内定として進みます）。案件の「失注」「終了」は状態記録として残り、Slackのメッセージは消えません。
・メンバータブの「完了」は共有メッセージへの✅＝確認済みとして扱われ、フォローアップ側で閉じられます。
・「削除」は「完了」とは別です。メール/Slackは記録上閉じるだけ（メッセージ・下書き自体は消えません）、カレンダーは予定自体を削除、入社はそのステージだけを閉じ、面談は段階ごとの削除ルール（準備=離脱、内定確認=クローズ、書類回収以降=完了と同じ扱い）に従います。削除の前に確認画面が出ます。
・完了済みタブの「未対応に戻す」は、次回同期で台帳（状態ファイル）に再開を記録して未対応に戻します。元のメッセージの✅は残りますが、再開記録が優先され、リマインドも再開日から再開します（面談は次の段階のタスクが送信済みだと戻せません）。
・入社日を登録すると次の同期でカレンダーに【入社】予定が作られ、入社準備タスクが流れます。結果（入社済み/キャンセル）は当月末まで表示されます。
・入社待ちの回収チェックリストでは、まだSlackに送られていない段階（書類回収・入力/申請・入職フォロー）も先にチェックできます。その段階が実際に送られた時点で、そのまま完了として消し込まれます（チェックを外せば取り消せます）。
・面談待ちの案件は「内定にする」ボタンで、内定確認タスクの送信を待たずに内定として進められます（表示は即時、状態記録への反映は次の同期です）。反映待ちの間は入社待ちの行や案件詳細から取り消せます。
・「内定まで一括で進める」ボタンは、残っている準備・内定確認タスクを段階順にまとめて完了し、そのまま内定まで進めます。途中で失敗した場合は、完了した分だけが記録され、内定までは進みません。
